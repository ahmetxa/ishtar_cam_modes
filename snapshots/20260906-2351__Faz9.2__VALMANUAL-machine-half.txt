=== NEW DEFECT: the PC-04 substitute command does not work ===
docs/release-checklist.md section 3a gives this as PC-04's healthy substitute:
  awk '/^      android[.]scaler[.]availableStreamConfigurations [(]d000a[)]/,/^      [a-z]/' cam.dump | grep 8192
It returns ZERO rows. The range end pattern ^      [a-z] also matches the
HEADER line itself (android... is lowercase at the same six-space indent), and
awk tests the end pattern on the same record that opened the range, so every
range is one line long. Measured: 13 header matches, 13 lines emitted.
The command therefore reports absence for a size that IS present, which is the
worst possible failure mode for a release gate - it fails silently and safe-looking.
Working replacement, flag-based so the header cannot close its own range:
  awk 'index($0,"(d000a)")>0 && $0 ~ /^      android[.]/ {n++; f=(n==1); next} f && /^      [a-z]/ {f=0} f' cam.dump
n selects the camera block in dump order; n==1 is camera 0.
